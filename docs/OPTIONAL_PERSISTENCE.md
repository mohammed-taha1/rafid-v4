# التخزين الاختياري والآمن

قاعدة بيانات Supabase ليست مطلوبة لنجاح تحليل MVP. لا يُخزن النص أو الملف أو التقرير افتراضيًا، ولا تعتمد النتيجة على اتصال قاعدة البيانات.

الاستخدام الوحيد المخطط له في المرحلة الأولى هو تقييم فائدة التحليل: اختيار واحد من «مفيد جدًا» أو «مفيد جزئيًا» أو «غير مفيد» وملاحظة اختيارية لا تطلب بيانات شخصية. لا يتضمن التقييم محتوى البحث أو اسم الملف.

قبل تفعيل الحفظ الاختياري يجب: طلب موافقة صريحة، تحديد مدة احتفاظ، توفير حذف، تفعيل RLS على جدول التقييمات، وعدم استخدام مفتاح service role في المتصفح. عند تعطل Supabase لا تتعطل النتيجة؛ يفشل التقييم بهدوء مع رسالة قصيرة قابلة للتجاهل.
