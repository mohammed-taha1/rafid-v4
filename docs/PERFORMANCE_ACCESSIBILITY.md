# الأداء والوصول

- لا تستخدم الواجهة صورًا كبيرة أو حركات ثقيلة، وملف Supabase المحلي هو أكبر أصل طرفي.
- تبقى ملفات PDF وDOCX محلية وتُقرأ فقط بعد اختيار المستخدم؛ لا تخزن النصوص أو النتائج في cache.
- الواجهة RTL، والأزرار قابلة للتركيز وتملك حالات hover وfocus، والمدخلات ذات labels ورسائل الأخطاء `role=alert`.
- يغطي CSS الهاتف الصغير والكبير والجهاز اللوحي وسطح المكتب عبر شبكة بطاقات متجاوبة.
- عند بدء تحليل جديد أو إلغائه يستخدم العميل `AbortController`؛ لا تستخدم نسبة تقدم زائفة.
