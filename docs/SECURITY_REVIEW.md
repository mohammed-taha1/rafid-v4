# مراجعة الأمان قبل الإطلاق التجريبي

## النطاق

راجعت متغيرات البيئة، الواجهة، إدخال الملفات، prompts، API، headers، التخزين، وسجل Git دون عرض أسرار.

## ما تم إصلاحه

- مفاتيح الخادم لا تدخل إعداد الواجهة، وملفات البيئة مستبعدة.
- يتحقق الإدخال من الامتداد وMIME والحجم والتوقيع، ولا يكتب ملفات مؤقتة.
- النص غير الموثوق محاط كبيانات في prompts، وتتحقق النتيجة من schema.
- API يستخدم rate limit، منع التحليل المكرر، مهلة، ورسائل آمنة بلا stack trace.
- headers تمنع framing وMIME sniffing، وCSP تقيد الأصول.
- لا يُخزن البحث أو الملف افتراضيًا.

## إجراء يدوي مطلوب

تدوير أي رمز وصول شاركه المالك خارج المستودع، وضع الأسرار في Render فقط، تفعيل RLS واختباره قبل أي تخزين اختياري، وتقييد OAuth redirect origins.

## مخاطر متبقية وقرار

يلزم اختبار حي لـGroq/ZDR وSupabase وRender قبل الإطلاق العام. القرار: مناسب لتجربة تجريبية مضبوطة بعد إتمام المتطلبات اليدوية، وليس إطلاقًا عامًا بعد.
